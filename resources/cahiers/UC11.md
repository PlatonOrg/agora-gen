# UC11 : Consulter les logs de generation

| Champ | Valeur |
|---|---|
| Description | Permet d'explorer l'historique des conversations de generation, leur detail et la configuration active de l'application. |
| Paquetage | Observabilite fonctionnelle |
| Acteurs | Enseignant, Administrateur |
| Preconditions | Utilisateur connecte, page Logs accessible. |
| Postconditions | Les sessions et details de generation sont consultables en lecture. |
| Importance | Moyenne |
| Frequence | Frequence variable |

## Scenario nominal

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Clique sur le bouton **"Logs"** dans le menu de navigation principal. | Navigue vers la page des logs et affiche un indicateur de chargement. |
| 2 |  | Charge et affiche la liste des sessions de generation passees (date, identifiant, statut). |
| 3 | Clique sur une session dans la liste. | Charge et affiche le detail de la session : liste des generations avec leur type et statut. |
| 4 | Utilise les filtres visuels pour trier les generations (ex : boutons **"Toutes"**, **"Exercice"**, **"Discussion"**). | Met a jour la vue filtree sans recharger la page. |
| 5 | Clique sur l'onglet **"Configuration"**. | Charge et affiche la configuration active de l'application (fournisseur LLM, parametres de generation, etc.). |

## Scenarios alternatifs

### A1 - Consultation de la configuration sans selectionner de session

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Arrive sur la page Logs. | Affiche la liste des sessions et les onglets disponibles ("Sessions", "Configuration"). |
| 2 | Clique directement sur l'onglet **"Configuration"** sans selectionner de session. | Charge et affiche la configuration active de l'application. |
| 3 | Consulte les parametres afffiches et peut revenir sur l'onglet **"Sessions"** a tout moment. |  |

## Scenarios d'exception

### E1 - Erreur de chargement de la liste des sessions

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Clique sur **"Logs"** dans la navigation. | Tente de charger la liste des sessions mais rencontre une erreur serveur ou reseau. |
| 2 |  | Affiche un message d'erreur explicite dans la zone de la liste (ex : "Impossible de charger les sessions. Reessayez."). |
| 3 |  | La navigation vers d'autres pages reste disponible, la page Logs n'est pas bloquee. |
| 4 | Peut actualiser la page ou reessayer ultierieurement. |  |

### E2 - Session introuvable ou erreur de detail

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Clique sur une session dans la liste. | Tente de charger le detail de la session mais la session est introuvable ou une erreur survient. |
| 2 |  | Affiche un message d'erreur dans la zone de detail (ex : "Session introuvable ou erreur de chargement."). |
| 3 | La liste des sessions reste affichee et l'utilisateur peut selectionner une autre session. |  |

## FQM (Fonction, Qualite, Mesure)

| Macro-fonctionnalite | Qualite attendue | Mesure / Critere |
|---|---|---|
| Consultation de l'historique | Tracabilite | Les sessions de generation sont listables et consultables en detail. |
| Lisibilite des etats | Ergonomie | Etats "chargement / succes / erreur" explicites sur toutes les zones de la page Logs. |
