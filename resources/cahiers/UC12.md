# UC12 : Consulter les statistiques administrateur

| Champ | Valeur |
|---|---|
| Description | Permet a un administrateur de consulter les indicateurs agreges (conversations, publications, echecs, temps moyen) sur une plage de dates choisie. |
| Paquetage | Administration |
| Acteurs | Administrateur |
| Preconditions | Utilisateur connecte avec le role Administrateur. |
| Postconditions | Les statistiques sont affichees sous forme de cartes indicateurs et d'une courbe journaliere pour la periode selectionnee. |
| Importance | Haute |
| Frequence | Faible a moyenne |

## Scenario nominal

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Clique sur le bouton **"Admin"** dans le menu de navigation principal. | Verifie que l'utilisateur possede le role Administrateur et charge la page d'administration. |
| 2 |  | Affiche la page avec les indicateurs pour la plage par defaut (ex : 7 derniers jours). |
| 3 | Pour changer la periode, clique sur un bouton de plage predefinit (**"7 jours"**, **"30 jours"**, **"365 jours"**) ou selectionne une plage personnalisee via les deux selecteurs de date **"Du"** et **"Au"**. | Met a jour les indicateurs et la courbe journaliere en fonction de la periode selectionnee. |
| 4 |  | Affiche les cartes indicateurs : nombre de conversations, publications reussies, echecs, temps moyen de generation. |
| 5 |  | Affiche la courbe d'activite journaliere pour la periode choisie. |
| 6 | Consulte les indicateurs et la courbe pour analyser l'activite. |  |

## Scenarios d'exception

### E1 - Acces refuse (utilisateur sans role Administrateur)

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Un utilisateur sans role Administrateur tente d'acceder a la page Admin (ex : en tapant l'URL directement). | Verifie le role de l'utilisateur et detecte qu'il n'est pas Administrateur. |
| 2 |  | Redirige l'utilisateur vers le workspace ou affiche un message d'acces refuse (ex : "Acces interdit. Cette page est reservee aux administrateurs."). |
| 3 | L'utilisateur est redirige et ne peut pas consulter les statistiques. |  |

### E2 - Plage de dates invalide

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Selectionne une date de fin anterieure a la date de debut dans les selecteurs de date personnalises. | Detecte que la plage de dates est invalide. |
| 2 |  | Affiche une indication d'erreur sur le selecteur de date (ex : mise en evidence en rouge, message "La date de fin doit etre posterieure a la date de debut"). |
| 3 | Corrige les dates selectionnees. | Met a jour les indicateurs avec la plage corrigee. |

### E3 - Erreur de recuperation des statistiques

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Selectionne une periode et attend les resultats. | Tente de recuperer les statistiques mais rencontre une erreur serveur ou reseau. |
| 2 |  | Affiche une banniere ou un message d'erreur en haut de la page (ex : "Impossible de charger les statistiques. Verifiez votre connexion et reessayez."). |
| 3 |  | Les cartes indicateurs affichent un etat de chargement echoue mais la navigation reste disponible. |
| 4 | Peut actualiser la page ou modifier la plage de dates pour reessayer. |  |

## FQM (Fonction, Qualite, Mesure)

| Macro-fonctionnalite | Qualite attendue | Mesure / Critere |
|---|---|---|
| Controle d'acces admin | Securite | Page accessible uniquement aux utilisateurs avec le role Administrateur. |
| Lecture des tendances | Pilotage | Indicateurs agreges et courbe journaliere disponibles sur une plage de dates parametrable. |
