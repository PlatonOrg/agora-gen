# UC10 : Sauvegarder automatiquement et reprendre un exercice

| Champ | Valeur |
|---|---|
| Description | Garantit la persistance locale et distante de l'etat de l'exercice pour permettre la reprise apres rafraichissement ou fermeture de page. |
| Paquetage | Continuite de travail |
| Acteurs | Enseignant, Administrateur |
| Preconditions | Workspace initialise avec un exercice en cours. |
| Postconditions | L'etat de l'exercice est conserve localement et en cache distant, puis rechargeable lors d'une nouvelle visite. |
| Importance | Haute |
| Frequence | Continue (en arriere-plan) |

## Scenario nominal

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Modifie des champs de l'exercice (titre, enonce, composants, etc.) dans le panneau d'edition. | Detecte les changements et sauvegarde immediatement l'etat dans le stockage local du navigateur (sans action de l'utilisateur). |
| 2 |  | Apres une courte pause sans modification, sauvegarde egalement l'etat sur le serveur en arriere-plan (sauvegarde distante silencieuse). |
| 3 | Ferme l'onglet ou rafraichit la page. |  |
| 4 | Rouvre AGORA et navigue vers le workspace. | Charge en priorite l'etat sauvegarde localement et l'affiche dans le panneau d'edition. |
| 5 |  | Tente en parallele de recuperer l'etat depuis le cache distant et synchronise si une version plus recente est disponible. |
| 6 | Retrouve son exercice dans l'etat ou il l'avait laisse. |  |

## Scenarios d'exception

### E1 - Echec de la sauvegarde distante

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Continue a modifier l'exercice normalement. | Tente la sauvegarde distante en arriere-plan et detecte une erreur reseau ou serveur. |
| 2 |  | Conserve la sauvegarde locale comme source de verite. |
| 3 |  | Peut afficher une icone ou une indication discrete (ex : icone de nuage barree) pour signaler que la synchronisation distante est en echec. |
| 4 | Peut continuer a travailler normalement. Ses donnees sont preservees localement. |  |

### E2 - Cache distant absent au rechargement

| Etape | Acteur | Systeme |
|---|---|---|
| 1 | Ouvre le workspace sur un nouvel appareil ou apres expiration du cache. | Tente de recuperer l'etat depuis le cache distant mais ne trouve aucune donnee. |
| 2 |  | Verifie si un etat local est disponible dans le navigateur. |
| 3 |  | Si un etat local est present : le charge et l'affiche. Si aucun etat n'est disponible : affiche un workspace vide sans message d'erreur bloquant. |
| 4 | Peut reprendre son travail depuis le cache local (si disponible) ou repartir de zero. |  |

## FQM (Fonction, Qualite, Mesure)

| Macro-fonctionnalite | Qualite attendue | Mesure / Critere |
|---|---|---|
| Autosave local | Resilience | Aucune perte de travail lors d'un simple rafraichissement de page. |
| Synchronisation distante | Continuite multi-session | Etat recuperable sur d'autres appareils tant que le cache distant est valide. |
